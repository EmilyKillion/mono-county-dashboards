    Weekly update

    1. Fill the yellow cells in RV_Tracker.xlsx (Weekly_Local, Weekly_ELR, Wastewater_Local, State_National, Flu_Age_Vax, Highlights, Config). Wastewater_History is read-only history.
    2. Commit the tracker to the GitHub repository next to index.html. The page loads it automatically; CDC data refresh on every page load.
    3. Use “Print / save PDF” for the leadership copy. All tabs print in order, one section per page.
